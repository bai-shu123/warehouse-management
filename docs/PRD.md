# 双库房服装库存台账

状态：设计稿 v0.1  
目标平台：电脑、手机、平板浏览器  
部署目标：GitHub + Supabase

## 1. 产品目标

为管理员、仓库员工和财务提供一个多人协作的服装库存台账。系统重点解决两类库存位置、跨库房运输、分批收货、按批次成本核算和可追溯更正。

第一版不做销售订单、收款、条形码和自定义属性。业务数据不自动翻译，界面文字支持中文、俄语和哈萨克语。

## 2. 角色与权限

| 角色 | 能看什么 | 能做什么 | 禁止 |
| --- | --- | --- | --- |
| 管理员 | 全部数据，包括采购价、成本、汇率和两个库房 | 管理用户、款式、图片、入库、运输、收货、取货、汇率、报表、回退和撤销回退 | 无业务限制，但所有改动仍写入日志 |
| 仓库员工 | 被分配的自有库房、可操作批次的日期和数量 | 确认到货、支持分批收货、登记取货 | 查看他人库房、采购价、成本、汇率；创建运输；回退历史记录 |
| 财务 | 两个库房的入库、取出、运输、数量统计和报表 | 在线查看、按条件筛选、导出 Excel/PDF | 查看采购价、成本、汇率；新增、修改、回退数据 |

管理员可以创建、停用账号，分配角色和仓库，重置密码。用户登录后可以独立选择中文、俄语或哈萨克语。

## 3. 核心业务对象

### 3.1 款式

- 款号/编号：必填、唯一。
- 款式名称：选填。
- 图片：选填，可上传多张并指定主图。
- 不按颜色、尺码或其他属性拆分库存。
- 库存维度为“款式 + 库房 + 批次”。款式总库存是批次余额的汇总。

### 3.2 数量

- 主数量单位为“包”。
- 管理员在批次或收货记录中填写实际件数，包内数量不假设恒定。
- 取货同时记录取出包数和实际取出件数。
- 包数和件数都参与余额校验；普通取货不能超过所选批次的剩余包数或件数。

### 3.3 价格与价值

- 采购价按人民币/件录入，只对管理员可见。
- 入库记录保存当天的人民币兑美元和美元兑坚戈汇率快照。
- 换算公式：`人民币金额 / 人民币兑美元汇率 * 美元兑坚戈汇率`。
- 历史成本永久使用入库时保存的汇率快照。
- 当前参考价值使用管理员最后维护的有效汇率重新计算，不改写历史成本。
- 汇率记录包含生效日期、数值、录入人、录入时间和备注，旧值不可覆盖。

## 4. 库房与运输流程

系统初始包含两个库房：

1. 他人库房：国内货物到达后的存放处。
2. 自有库房：实际经营使用的库房。

### 4.1 国内运输到他人库房

`创建国内运输单 -> 国内运输中 -> 到达他人库房 -> 管理员确认收货`

- 管理员录入款式、预计包数、预计件数、发货日期、预计到达日期、采购价、备注。
- 收货可以分批进行，每次记录实际包数、实际件数、日期和备注。
- 未收部分继续显示为“国内运输中”。
- 到货后，实际收货数量才进入他人库房可用库存。
- 员工不查看和操作他人库房；国内运输的到货由管理员确认。

### 4.2 他人库房调拨到自有库房

`创建调拨 -> 调拨运输中 -> 自有库房分批收货 -> 已完成`

- 管理员创建调拨单，选择来源库房、目标库房、款式和批次。
- 发运后，来源批次的可用库存减少，运输数量在来源和目标两侧都显示为“运输中”。
- 员工只在被分配的自有库房确认到货；允许多次部分收货。
- 每次收货同步扣减运输余额并增加自有库房可用库存。
- 货物数量不一致时，系统生成管理员待办。管理员选择继续等待、标记丢失、标记损坏或填写其他处理结果。

### 4.3 取货

- 员工从自有库房登记取货。
- 记录款式、手动选择一个或多个批次、取出包数、实际取出件数、领取人、日期和备注。
- 日期默认使用哈萨克斯坦当地时间 `Asia/Almaty`，允许手动调整。
- 普通取货不允许超过所选批次余额；提交后立即影响库存，管理员只需过目。

## 5. 回退与审计

- 原始记录不可删除。
- 管理员可以回退任意历史记录，必须填写原因。
- 回退前显示影响范围，并要求二次确认和管理员密码/PIN验证。
- 回退写入一条反向操作，原记录标记为“已回退”。
- 任意已回退记录都可以“撤销回退”，恢复原库存变更；撤销同样写入新日志。
- 回退可能导致库存出现负数，这是允许的例外；普通取货仍严格校验批次余额。
- 每条业务操作记录操作者、时间、设备会话、前后数量、原因和关联记录。

## 6. 页面与功能范围

### 管理员

- 总览：两个库房的可用库存、运输中、异常待办、近期操作。
- 款式管理：新建/编辑款号、名称和图片。
- 入库与国内运输：创建运输、分批收货、异常处理。
- 库房调拨：选择批次发运、查看运输进度、确认收货。
- 取货记录：查看员工提交记录、筛选、回退和撤销回退。
- 汇率与价格：维护历史汇率、查看历史成本和当前参考价值。
- 用户与权限：创建/停用账号、角色、仓库分配、重置密码。
- 报表：在线查看并导出 Excel/PDF。

### 仓库员工

- 我的库房：可用包数/件数和运输中数量。
- 待收货：确认全部或部分到货，提交异常说明。
- 取货：选择款式和批次，填写包数、件数、领取人、日期、备注。
- 我的记录：查看自己提交的操作状态。

### 财务

- 入库、取出、运输台账。
- 按日期、款式、库房、操作类型和运输状态筛选。
- 数量统计和趋势汇总。
- 导出 Excel/PDF，字段和界面跟随当前用户语言。

## 7. 多语言与数据隐私

- 界面固定文案使用 i18n key，支持中文、俄语、哈萨克语。
- 业务数据（款式名称、备注、领取人）保留录入原文，不自动翻译。
- 管理员可以补充三种语言的系统文案；第一版不要求业务数据多语字段。
- 采购价、成本和汇率不能仅靠前端隐藏，必须在 Supabase 数据库权限和安全视图层隔离。

## 8. 验收标准

1. 仓库员工无法通过页面或数据库接口读取采购价、成本和汇率。
2. 普通取货无法超过所选批次的包数或件数余额。
3. 国内运输和库房调拨都支持部分收货，剩余数量继续显示运输中。
4. 调拨运输在两侧都能显示同一运输数量，收货后才增加目标库房库存。
5. 任何回退和撤销回退都不删除原始记录，库存和审计链可重放。
6. 历史成本不随新汇率改变，当前参考价值可以按最新汇率重算。
7. Excel/PDF 导出遵守角色权限，财务导出不含敏感金额字段。
8. 三种语言可以按用户账号独立切换，桌面、平板和手机布局均可完成收货与取货。

## 9. 第一版明确不做

- 条形码和扫码。
- 销售订单、客户、收款、应收账款。
- 自定义属性和颜色/尺码独立库存。
- 自动从银行或外部汇率接口抓取汇率。
- 邮件、短信、WhatsApp 等外部通知。
